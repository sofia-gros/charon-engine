# 仕様 18: スマホの操作 (Terraria Android 型)

**方針【決定】**: 操作は Android 版 Terraria を**完全に模倣する** (持ち主の指示: 「一番操作しやすかった」)。配置・動き・ボタンの意味を揃える。ただし、**見た目の素材 (アイコン・絵・文字の字体・名前) は模倣せず、自作する** (操作の仕組みは真似てよいが、他社の絵は使えない)。

この仕様は、持ち主が示した 4 枚のスクリーンショット (家の中・インベントリを開いた画面・ボス戦・ブロックを掘る画面) から読み取れることと、公開されている Terraria の操作の説明から書いた。**画像から確かでないものは「要確認」と書き、実機で触って直す**。M22 (建築の操作) で実装する。今の操作 (仕様 10 §11: 浮動の移動パッド・相対ポインター) は、これに置き換える。

## 2. カーソルの操作 (使うボタン)

画像 4 から、次の動きが読み取れる。

- プレイヤーのまわりに、**届く範囲を示す破線の円**が出る (半径 = 届く距離)。
- 円の中に、**カーソル** (黄色い四角、ブロックに揃う) が出る。ブロックを選んでいる・つるはしのときは、置ける・掘れるブロックの上に出る。
- 画面の上に、選んでいるアイテムの名前と数が出る (`いしブロック (13)`)。
- 右のスティックのつまみを動かすと、カーソルが円の中を動く。つまみを押している間、選んでいるものを、カーソルの場所に**使う**。

【決定】次のとおりに実装する。

1. **使うボタン**に触れた瞬間から、離すまで、選んでいるアイテムを使う (掘る・置く・撃つ・振る)。
2. 触れたまま**ドラッグ**すると、カーソルが動く。カーソルの位置 = プレイヤーの中心 + (つまみのずれ ÷ 半径) × 届く距離。ずれが半径に届けば、円の縁。
3. ブロック・つるはし・粉など、ブロック単位で使うものでは、カーソルは**ブロックの格子に揃う** (8×8 セル、仕様 17)。武器・道具では、揃えない (向きだけ使う)。
4. カーソルが、置けない場所・届かない場所なら、枠を赤にして、使っても何も起きない。
5. **スマートカーソル** (左下の `+` で切り替え、【確認済み】): **つまみのずれの大きさに関係なく、倒した向きに、カーソルが届く範囲の円の縁へ、すぐに (補間なしで) 動く**。倒す向きを変えれば、縁の上を、向きに合わせて一瞬で移動する。ブロックを掘る・置くときは、その向きの直線上で、**最初に当たる掘れるブロック**または**置ける場所**に自動で合わせる (届く範囲の中で)。切ってあるときは、1〜4 のとおり、ずれの大きさでカーソルが円の中を動く。
6. 画面を**直接タップ**してカーソルを置く方式は、**作らない** 【確認済み: スティックのようにカーソルを動かす】。

武器のときの向きは、カーソルの方向。つまみを倒した向きに撃つ (今のポインターの向きと同じ考え方)。

### 2.1 フックのスティック (使うボタンの左隣の、小さなスティック) 【確認済み】

- **傾けて離すと、離した向きへ、ワイヤーフックを飛ばす** (今のフック、仕様 10 §9 の `GameInput::tool`・`aim`)。向きは、離した瞬間のつまみの傾き (傾きの大きさは関係ない。しきい値 = 半径の 0.3 より小さければ、傾けていないものとして扱う)。
- 傾けている間は、向きを示す線 (矢印) を、プレイヤーから出す。使うボタンのカーソルとは**独立**で、同時に使える (右の親指でカーソル、右の人差し指でフック、など)。
- **しきい値より小さい傾きで離した (タップ)**: すでにフックが飛んでいる・張っているなら、**切り離す**。何もなければ、何も起きない (【要確認】)。
- フックが張っている間の、巻き取り (今は `tool` を押し続けると巻き取る) の操作は、【要確認】: 案は、「張っている間にフックのスティックに触れ続けると巻き取る」。
- エンジン側: 離した 1 tick だけ `tool` を真にして発射する (押し続けない)。巻き取りは、別の入力として扱う。同期 (Lockstep) の入力は変えない (`tool` と `aim` のまま)。

## 4. 実装の分け方 (M22)

1. 画面の部品の配置と描画 (今の `touch_pad` を作り直す)。素材は自作。
2. カーソルとブロックの格子への吸着、届く範囲の円、置ける・置けないの枠。
3. ホットバー (10 枠、タップで選択、`...` でインベントリ)。
4. インベントリ・クラフトの画面 (半透明の格子、絞り込み、`Craft`)。
5. 体力のハート・マナの星、アイテム名の表示。
6. 実機で触って、配置・大きさ・反応を調整する。

## 5. 確認の結果 (持ち主の回答、2026-11-13)

1. 左スティックの上では**ジャンプしない** (ジャンプは右の `^` ボタン)。
2. 左下の `+` は**スマートカーソルの切り替え**。
3. 右下の使うボタンは、**スティックのようにカーソルを動かす**。スマートカーソルのときは、倒した向きに、**円の縁へ爆速で (すぐに) 動く**カーソルになる。直接タップの方式は作らない。
4. ホットバーは**横一列**。
5. 右スティックの左隣の小さな丸は、**フックを飛ばす小さなスティック** (傾けて離した向きへ飛ぶ、§2.1)。クイックボタンではない。弓などのアイコンは、見た目のこと。

まだ残る細部 (実装しながら実機で決める): フックが張っている間の巻き取りの操作 (§2.1)、スマートカーソルの「最初に当たるブロック」の探し方 (直線上か、円の縁に近い順か)、届く距離 (ブロックの数)、ホットバーの枠の大きさ。
