# 仕様 21: 冒険の世界の地形 (M24)

`charon_world::terrain::AdventureGenerator`。製品版のデモ (Terraria 型) の世界。デモの部屋・剛体・背景はない。整数だけで、他のチャンクを参照せず、決定的 (仕様 04 §4)。同じ `seed`・座標なら、生成の順序やスレッドによらず同じセルになる。

## 1. 座標と層

y が大きいほど下。表面の高さの基準 `SURFACE_BASE` = 200。底 `BOTTOM` = 1400 (`SURFACE_BASE + 1200`) 以上は、壊せない境界 (`boundary`)。出発点は x = 0 の表面 (`spawn_point`、16×24 のプレイヤーが立つ位置)。

| 深さ (表面から) | 中身 |
|---|---|
| 上 | 空 |
| 0〜 | 表面の層 (バイオームで違う、§2) |
| 26〜 | 洞窟が始まる (§3) |
| 石の層 | 石。鉱石 (§4)・地下の水と溶岩 (§5) |
| 底の手前 24 セル | 空洞は溶岩の湖 |
| `BOTTOM`〜 | 境界 |

表面の高さは、2 つのノイズ (幅 160 と 40) の丘。出発点の左右 24 セルは**平ら**で、そこから 64 セルかけて丘になる。

## 2. バイオーム (x の 512 セルごと)

出発点の区画 (x = 0 を含む) はいつも森。そのほかは seed で、森 (2/5)・砂漠 (2/5)・氷原 (1/5)。

| バイオーム | 表面の層 | 池 |
|---|---|---|
| 森 | 草 2 セル + 土 (22〜29 セル) | あり |
| 砂漠 | 砂 40 セル | なし |
| 氷原 | 氷 4 セル + 土 | あり |

池: 区画 (96 列) の 1/4 に、幅 44・深さ最大 12 の水たまり (地面と同じ高さまで水)。

## 3. 洞窟

表面から 26 セルより深いところを、3 つで掘る (座標を歪めたノイズ、整数)。深いほど広い。

1. **大広間**: ゆるい塊。しきい値が深さとともに広がる。
2. **坑道**: ノイズが中央値に近い帯 (2 本)。幅が深さとともに太る。
3. **立て坑**: 表面から深さ 100 までの縦の穴 (区画 160 列の 1/3。**x = 160〜319 の区画は必ずある**)。出発点から歩いて洞窟へ降りられるようにする。

## 4. 鉱石

石の中の塊 (40×40 の区画の一部 × ノイズ)。石炭 (深さ 40..520)・鉄 (130..950)・金 (360 以上)。

## 5. 地下の水と溶岩

深さ 60 以上の空洞に、48×48 の区画の 1/6 で、区画ごとの水面より下に液体が溜まる。溶岩の割合は、深さに比例 (表面 0% → 底 100%)。

## 6. 構造物 (ブロックでできた建物)

どれも `FLAG_BLOCK` の完全な 8×8 のブロックだけでできている (仕様 17)。形は、文字の絵 (`#` 石・`W` 木・`.` 空洞) で、空洞は地形を消す。壁に開いた口が、洞窟とつながる。

- **ダンジョン**: 区画 (256×192 セル) の 1/3 に、広間・塔・地下墓所のどれか。表面から 120 セルより深く、底の 60 セル手前まで。
- **家**: 森の区画 (192 列) の 1/3 に、木の家。足元の地面は、ブロックの格子に合わせて平らにならす。

## 7. 使い方

`charon_app::demo::open_adventure(config, seed)` が世界を開く。`run_demo` は、`DemoConfig::adventure` が真なら、これを開く (`discover` では、環境変数 `CHARON_WORLD=demo` でないとき真。Android は常に真)。セーブは `saves/demo/adventure-<seed>`。新しい世界 (`Random Seed`) も同じ種類で開く。

## 9. まだやっていないこと

- **溶岩の熱が眠る** (仕様 02 §9): 溶岩のセルが毎 tick 温度を更新して、眠らない。シミュレーションの結果が変わるので、持ち主の確認が要る (M24 の残り)。
- 敵の配置 (M25)。洞窟の中の宝箱・照明などの飾り。層ごとの背景の絵。
