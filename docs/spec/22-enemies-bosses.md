# 仕様 22: 敵 (武器・防具・戦利品・ボス) と自動のスポーン (M25)

敵は、プレイヤーと同じ仕組み (アイテム仕様 19・戦闘仕様 20) で武器・防具を使う。

## 1. 敵の定義 (`enemies.ron`) の追加項目

| 項目 | 意味 |
|---|---|
| `weapon: Some("アイテム名")` | 持っている武器。生まれたときに装備する |
| `armor: ["アイテム名", ...]` (8 個まで) | 持っている防具。**枠ごとに、強さの点数が最も高いもの**を装備する (自動装備、仕様 19 §6)。防御・耐性は、プレイヤーと同じ式で体力の表に写る |
| `loot: [("材質", 個数), ...]` | 倒したときに落とす材質のセル (`cells:` の接頭辞は任意)。普通のドロップとして落ちる (仕様 10 §19) |
| `boss: true` | ボス。体力のバーが画面の上の中央に出る。倒すと `GameEvent::BossDefeated` |

アイテム名が定義にないときは、**敵を作らずに** `GameError::UnknownItem` で失敗する (ID も使わない)。

エンジンの既定の敵: `walker`・`shooter` (これまで)、`skeleton` (石の剣・石の兜と胸当て)、`archer` (弓)、`mage` (火の玉を撃つ、火の指輪)、`golem` (ボス、体力 600、大きな拳・石の防具、鉱石を落とす)。

## 2. 武器を使った攻撃

- **近接** (`Melee`): 目標が前の箱 (体の半幅 + 20 セル、縦 ±14) に入ったら斬る (間隔 20 tick)。プレイヤーにだけ当たる。
- **遠距離** (`Ranged`): 目標の方へ、遠いほど上へ向けて矢を撃つ。距離をとる (`sight` の半分のあたり)。
- **杖** (`attack: Some("呪文")`): これまでどおり。
- 倒れたら、戦利品を落とし、装備を消す。

## 3. 自動のスポーンと削除 (`Spawner`、`GameState::spawner`)

`step_spawner` を毎 tick 呼ぶ (App の `Sim::tick` が `game.step` のあとに呼ぶ)。プレイヤー (杖を持つ、敵でない、生きている者) がいなければ何もしない。

- **削除**: どのプレイヤーからも `despawn` セル (既定 320) より遠い敵、またはチャンクが読み込まれていない場所の敵は、**倒さずに**消す (戦利品・出来事なし)。
- **スポーン**: `interval` tick (既定 90) ごとに、確率 2/3 で試す。プレイヤーの 1 人を選び、横へ `near`..`far` セル (既定 120..200、画面の外) 離れた列で、体 (16×24) が入る空きと、足元の固体のある、いちばん上の場所を探す。その y が入る規則 (`SpawnRule { enemy, min_y, max_y, weight, boss }`) の中から、重みで 1 つ選ぶ。ボスでない敵は `max_enemies` (既定 8) まで。ボスは、同時に 1 体まで、まれに (試す 12 回に 1 回) 出る。
- すべて `rng::hash(seed, tick, ...)` だけで決まり、同じ seed と入力なら同じ結果。
- `Spawner::adventure()`: 冒険の世界 (仕様 21) の規則。第4段階の資源分布と結んだ現在の出現帯は [仕様 26 §4](26-world-progression.md#4-t323-敵ボス): 地表 (y 150..260) は歩く敵と弓兵、浅い石炭帯 (260..560) は骸骨と射手、鉄/金の探索帯 (560..920) は骸骨と魔術師、深い金帯 (920..1400) は魔術師とゴーレム (ボス)。y の範囲は終端を含まない。旧帯 (地表 150..270、骸骨/射手 260..900、魔術師 380..1400、ボス 700..1400) は T32.3 で資源の段階に合わせて変更した。

## 4. 画面

ボスがいる間、体力のバー (赤、名前つき) を画面の上の中央に出す。

## 5. テスト (`crates/charon-game/tests/enemies_m25.rs`)

| テスト | 確認 |
|---|---|
| `enemies_auto_equip_the_best_carried_gear` | 枠ごとに最も強い防具を選ぶ。防御・耐性が体力の表に写る |
| `a_bad_gear_name_fails_without_creating_the_enemy` | 不正な名前は何も変えない |
| `a_skeleton_swings_and_armor_reduces_the_damage` | 近接で斬る。プレイヤーの防具で減る |
| `an_archer_keeps_its_distance_and_shoots_arrows` | 距離をとって矢を撃つ・当たる |
| `a_mage_throws_fireballs` | 火の玉・火 |
| `defeated_enemies_drop_loot_and_bosses_announce_themselves` | 戦利品・`BossDefeated` |
| `the_spawner_spawns_around_the_player_and_despawns_far_enemies` | 上限・距離・決定性・遠い敵の削除 |
| `spawn_rules_respect_depth_and_bosses_are_unique` | 深さの規則・ボスは 1 体まで |
