# 仕様 28: Android 版 Terraria の操作の模倣 (M34、v0.1.0)

対象: M34。持ち主の 2026-11-15 の指示「操作を完全に Android 版 Terraria と同じものにする。すべて終わり次第 v0.1.0 として公開する。わからない部分は適切に判断して解決する」への対応。
根拠は [TERRARIA_ANDROID_UI_REFERENCE.md](../TERRARIA_ANDROID_UI_REFERENCE.md) (公開資料の調査。`§` はその章)。**絵・文字の字体・名前・音は模倣せず自作する**方針 ([仕様 18](18-terraria-touch.md)) は変えない。

## 1. 方針と、判断したこと

公開資料で分からないこと (資料 §12) は、次のとおり**私が決めた**。実機の Terraria と並べて確かめていないので、**実機との一致を主張しない**。

| 分からなかったこと | 決めたこと | 理由 |
|---|---|---|
| 世界を指で押したまま動かしたとき | カーソルが**指についてくる** (なぞって連続で置く・掘る) | 「長押しで撃ち続ける」「ドラッグで掘り進める」遊び方に合う |
| 世界へのタップと、使うボタンのスティックの優先 | **使うボタンの指がある間は、スティックが優先** | 狙っている途中に、別の指で狙いが飛ばないように |
| ピンチを始めた指が、アイテムを使ってしまう (Terraria の注意書き) | **2 本目が世界に触れたら、使うのをやめる** | 資料に「道具を持ったままピンチすると壊してしまう」とあり、避けたほうが安全 |
| ダブルタップの時間 | 0.3 秒 | 資料に数値がない |
| スティックの「上へ倒した」の大きさ | 半径の 0.5 | 歩く 0.3 とは区別する |
| スティックの感度 | 50〜150% (既定 100%)。倒れに掛ける | 資料の設定のとおり |
| アイテムごとの「狙う方式」の既定 | ブロック・設備・消耗品は **Aim Only**、つるはし・斧・武器・そのほかは **Aim & Use** | 資料 §4.3 の「建築は狙うだけがよい」から |
| 「中心をたたいただけ」では使わないもの | ブロック・設備・消耗品 (倒れが 150‰ 未満では使わない) | 資料 §4.3 |
| スマートカーソルの既定 | つるはし・斧は On、ほかは Off | 資料 §4.5 の「掘る方向を決める」用途 |
| オートセレクトで暗い所に置く明かり | **対象外** (たいまつにあたるアイテムがない) | §3 |
| ホットバーの向きの既定 | **Horizontal** (持ち主の確認した形) | 資料の既定は Vertical だが、持ち主の実機は横。Vertical も選べる |
| 左スティックの上のジャンプ | **Double Tap** (既定)。Disabled / Single Tap / Swipe を選べる | 資料の既定。1 回だけ倒してもジャンプしないので、持ち主の確認と矛盾しない |

仕様 18 の「画面を直接タップするカーソルは作らない」は、**このタスクで取り下げる** (仕様変更)。理由: Terraria 本体は直接タップでアイテムを使える・ブロックを置ける。持ち主も 2026-11-15 に確認した。

## 3. 対象にしないもの (v0.1.0 では作らない)

**Charon にその仕組みがないもの** (操作だけ作っても動かない):

| Terraria | 理由 |
|---|---|
| クイックバフ | 良い効果 (バフ) の仕組みがない。あるのは燃える・濡れる・毒の状態異常だけ |
| マウント、ダッシュ、防具のセット能力の発動ボタン | マウント・ダッシュがない。セット能力は常に発動する |
| 配線・ブロック入れ替え・ルーラー・ペイントのツール、オートセレクトの明かり | 該当するアイテムがない |
| ミニマップ、全画面マップ、ピン、ピンチでマップを開く | マップがない |
| チャット、エモート、ハウジング、NPC・店、図鑑、ジャーニーの力、PvP とチーム、ロードアウト | 該当するシステムがない |
| スタックの分割 (Split)、並べ替え (Sort) | 持ち物が**種類ごとの個数**で、物理的な枠のスタックではない ([仕様 19](19-items.md) §3.1)。物理スタックへの移行が前提 |
| コイン・弾の専用枠 | 同上 |

**大規模なため、後続に回すもの** (持ち主の指示の「完全」からは外れるが、v0.1.0 に入れない):

| Terraria | 状態 |
|---|---|
| 操作エディタ、4 つのプロファイル、ラジアルボタン、ボタンごとのマルチタッチ、ボタンの位置・大きさの編集 | 未実装。仮想コントロールの位置は固定 |
| ページ群 (左右のタブ、開閉の 3 段階、動かせる) | 未実装。持ち物は 1 つの画面 |
| 安全な範囲 (切り欠き) の設定 | 未実装 |
| 体力・マナの見た目 3 種類 (Classic / Fancy / Bars) | 未実装。1 種類 |

これらは**実装していないことを、v0.1.0 の説明に書く**。

## 4. 共通の約束

- 浮動小数点は、`charon-core` のシミュレーションに使わない。タッチの部品 (`touch_pad`) と画面の計算は浮動小数点でよい ([CLAUDE.md](../../CLAUDE.md))。ゲームの状態を変える判断 (`charon-game`) は整数だけ。
- 持ち物と世界の変更は、これまでと同じく `GameState` の関数を通す。新しい設定は `settings.ron` に `#[serde(default)]` で足し、版は上げない (古いファイルをそのまま読める)。
- 画面の部品の位置は、既存の `Layout` に足す。足した部品も、既存の部品と重ならず、画面に収まる (`terraria_layout_matches_the_reference_positions` を拡張)。
- 失敗したら何も変えない (アイテムを使えない・足りない)。

## 5. T34.1 世界の直接タッチとピンチ

### 規則

- **世界の指**: 新しく触れた指が、仮想コントロール・ホットバーのどれにも当たらず、UI (egui) も使っていないとき、その指は世界の指になる。
- **カーソル**: 触れている間、カーソルは指の場所のセル (`origin + 画素 / zoom` の切り捨て) にある。ドラッグで指についてくる。届く範囲 (`REACH_CELLS`) の円に収め、ブロックを使うもの (置く・掘る) は、ブロックの格子に揃う。マウスと同じ計算 (`cursor_from_offset`)。
- **使う**: 世界の指が触れている間、選んでいるアイテムを使う (間隔は使うボタンと同じ)。武器は、プレイヤーから指の場所への向きへ撃つ。
- **優先**: 使うボタンの指があるとき、世界の指はカーソルも使うことも動かさない。
- **ピンチ**: 世界の指が 2 本になったら、使うのをやめ、2 本の距離の比でズームする (`clean_zoom(開始のズーム × 距離 / 開始の距離)`、サンドボックスのピンチと同じ)。1 本に戻ったら、その指は使わない (指を離して触れ直すまで)。
- 世界の指も、ほかの指と同じく、`release_all` と、離した・取り消したイベントで必ず離れる。

### テスト

| テスト | 確認 |
|---|---|
| `world_touch_is_taken_only_outside_controls` | 部品に当たらない新しい指だけが世界の指になる |
| `world_tap_places_a_block_at_the_touched_cell` | ブロックを選んでタップ → 触れたセルのブロックの格子に置かれる (ヘッドレス) |
| `world_drag_follows_the_finger_and_places_continuously` | 押したまま動かすと、カーソルが追い、通ったブロックに続けて置く |
| `world_touch_out_of_reach_does_nothing` | 届かない場所では何も起きず、状態は `OutOfReach` |
| `world_touch_aims_weapons_toward_the_finger` | 武器は、指の方向へ向く |
| `use_button_wins_over_world_touch` | 使うボタンの指があると、世界の指は動かさない |
| `two_world_fingers_pinch_zoom_and_stop_using` | 2 本でズームし、使うのをやめる。1 本に戻っても使わない |
| `world_touch_never_sticks` | 離す・取り消し・`release_all` で押されたままにならない |

## 6. T34.2 狙う方式・サブ攻撃・スマートカーソルの記憶

### 規則

- **部品を足す**: サブ攻撃ボタン (使うボタンの左上、半径 `1.0u`)、狙う方式の切り替えボタン、スマートカーソルの `+` はそのまま。
- **種類 (`ItemCategory`)**: `Block` (置くもの・設備)、`Tool` (つるはし・斧)、`Weapon` (武器・セルのアイテム・何も選んでいない)、`Other` (消耗品・そのほか)。
- **Aim Mode**: `AimUse` / `AimOnly`。既定は `Block` と `Other` が `AimOnly`、`Tool` と `Weapon` が `AimUse` (§1)。
  - `AimUse`: 使うボタンのスティックに触れている間、使う。
  - `AimOnly`: スティックはカーソルを動かすだけ。**サブ攻撃ボタンを押している間**、カーソルの場所に使う。
  - `AimUse` でも、`Block`・`Other` は倒れが 150‰ 以上になるまで使わない。
- **切り替えボタン**: 設定 `aim_mode_toggle` に従う。`ByItemType` (既定) は今の種類の方式を反転して覚える。`ForAllItems` は全部の種類を同じにする。`AlwaysAimUse` は常に `AimUse`、`AlwaysAimOnly` は常に `AimOnly` で、ボタンは何もしない。
- **スマートカーソル**: 設定 `smart_cursor_toggle` の `ByItemType` (既定) / `ForAllItems` / `AlwaysOff` / `AlwaysOn`。`+` が同じように働く。既定は `Tool` が On、ほかは Off。
- **感度**: 設定 `aim_sensitivity` (50〜150、既定 100)。使うボタンの倒れ (‰) に感度 / 100 を掛ける (1000 で止める)。スマートカーソルの向きは変わらない。
- 記憶は `settings.ron` に保存する。

### テスト

| テスト | 確認 |
|---|---|
| `aim_only_moves_the_cursor_without_using` | 既定でブロックを選ぶと、スティックだけでは置かない |
| `action_button_uses_at_the_cursor_in_aim_only` | サブ攻撃ボタンを押している間、カーソルの場所に置く |
| `aim_and_use_keeps_the_weapon_firing_with_the_stick` | 武器は、スティックで撃ち続ける |
| `centre_tap_does_not_place_blocks` | 倒れが 150‰ 未満では、ブロック・消耗品を使わない |
| `aim_mode_is_remembered_by_item_category` | 種類ごとに覚える。ほかの種類は変わらない |
| `aim_and_smart_toggle_modes_follow_settings` | `ForAllItems`・`Always*` の動き |
| `aim_sensitivity_scales_the_tilt` | 50% と 150% の倒れ。1000 で止まる |
| `aim_settings_roundtrip_and_clamp` | 保存・読み込み、範囲外を収める、古い設定ファイルの既定値 |

## 7. T34.3 ジャンプの方式・クイック回復/マナ・ホットバーのタップ

### 規則

- **Up To Jump** (設定 `up_to_jump`): `DoubleTap` (既定) / `SingleTap` / `Swipe` / `Disabled`。左スティックの倒れが上へ半径の 0.5 を超えることを「上」とする。
  - `DoubleTap`: 0.3 秒以内に、上を 2 回 (いったん戻して) 倒すとジャンプ。**そのまま倒し続けると、ジャンプを押し続ける** (浮遊・高く跳ぶ)。
  - `SingleTap`: 上へ倒すとジャンプ。倒し続けている間、押し続ける。
  - `Swipe`: 倒した向きが上で、動きの速さが半径の 0.5 を 0.15 秒で超えたとき。以降は倒し続けている間、押し続ける。
  - `Disabled`: 上へ倒してもジャンプしない。
  - **横・下の倒しは、飛行を一時止める** (倒している間は押さない)。上へ戻すと、もう一度押す。
- **クイック回復**: `GameState::quick_heal`。持ち物の `Consumable` で `heal > 0` のうち、足りない体力を**回復しきれる**もののうち回復量が最小のもの、なければ回復量が最大のものを使う。同点は `ItemId` の小さいもの。満タン・使えるものがない・使用間隔 (40 tick) の間は何もしない。ボタンに使うアイテムの名前を出す。
- **クイックマナ**: `GameState::quick_mana`。`mana > 0` の消耗品のうち `ItemId` が最小のもの。杖のマナが満タン・ないときは何もしない。
- **ホットバーのタップ**: 消耗品の枠をタップしたら、選ぶと同時にすぐ使う (間隔の間は選ぶだけ)。

### テスト

| テスト | 確認 |
|---|---|
| `double_tap_up_jumps_and_hold_keeps_jumping` | 2 回で跳び、倒し続けると押し続ける。1 回だけでは跳ばない |
| `double_tap_window_expires` | 0.3 秒を超えたら跳ばない |
| `single_tap_swipe_and_disabled_up_to_jump` | 3 つの方式の動き |
| `side_or_down_pauses_flight_until_up_again` | 横・下で止め、上で再開 |
| `quick_heal_chooses_the_least_wasteful_potion` | 回復しきれる最小、なければ最大 |
| `quick_heal_and_mana_do_nothing_when_full_or_empty` | 満タン・なし・使用間隔 |
| `quick_mana_uses_the_first_mana_potion` | 最小の `ItemId` |
| `hotbar_tap_uses_a_consumable_at_once` | 消耗品はタップですぐ使う。道具・武器は選ぶだけ |

## 8. T34.4 オートセレクト・インタラクト・ロックオン

### 規則

- **オートセレクト** (部品を足す、設定 `auto_select_mode`: `Hold` 既定 / `Toggle`): 有効な間、世界を使う場所 (世界の指・スティックのカーソル) の対象で、使う道具を**一時的に**選ぶ。持ち物の中から選び、ホットバーの選択は変えない。
  - 対象が固体のブロック: その材質を壊すのに使う道具 (`harvest_tool`、木は斧、ほかはつるはし) のうち、力が最大のもの。なければ何もしない。
  - 空きの場所: 何もしない (明かりのアイテムがない)。
  - 選ばれた道具を、ホットバーの横の追加の枠に出す。
- **スマートインタラクト** (部品を足す): 押した 1 回だけ働く。カーソルのブロックに有効な**箱**があり届くなら、開ける。
- **近接インタラクト**: 歩いておらず、狙ってもおらず、カーソルが別の箱の上にないとき、プレイヤーの足元 (中心のブロックと左右・下の隣) の最も近い有効な箱を開ける。
- **ロックオン** (部品を足す、設定 `lock_on_priority`: `ClearestLine` 既定 / `TargetClosest`): 押すとロックし、もう一度押すと解除、ロック中に押すと次の候補へ。
  - 候補: `LOCK_RANGE` (= `2 × REACH_CELLS` = 96 セル) 以内の生きている敵。`ClearestLine`: プレイヤーから見通せる敵のうち、**カーソルに最も近い**もの。`TargetClosest`: 壁を無視して**プレイヤーに最も近い**もの。
  - ロック中は、狙いが毎フレーム、プレイヤーから対象へ向く。対象が死ぬ・範囲を出る (`ClearestLine` では、見通せなくなって 60 tick 続く) と解除する。
  - ロック中も、ブロックを置ける。
  - 画面には、対象のまわりに黄色の三角を 3 つ、狙える敵には小さな三角を出す。
- ロックオンの判断は `charon_game::targeting` (整数だけ)。

### テスト

| テスト | 確認 |
|---|---|
| `auto_select_picks_the_best_tool_for_the_target` | 石 → つるはし、木 → 斧、力が最大のもの。ホットバーの選択は変わらない |
| `auto_select_ignores_empty_targets_and_missing_tools` | 空き・道具なしは何もしない |
| `smart_interact_opens_the_chest_under_the_cursor` | カーソルの箱を開ける。届かなければ開けない |
| `proximity_interact_opens_the_chest_at_the_feet` | 足元の箱。動いている・別の箱にカーソルがあるときは開けない |
| `lock_on_picks_by_priority` | 2 つの優先 (見通しの有無、距離) |
| `lock_on_follows_and_releases` | 追う・解除 (死亡・範囲外・見通しの喪失) |
| `lock_on_cycles_to_the_next_target` | ロック中に押すと次の候補 |
| `lock_on_still_allows_placing_blocks` | ロック中もブロックを置ける |
| `lock_on_aims_weapons_at_the_target` | 武器が対象へ向く (ヘッドレス) |

## 9. T34.5 ホットバー・体力・マナ・ツールチップ

### 規則

- **ホットバーの向き** (設定 `hotbar_orientation`: `Horizontal` 既定 / `Vertical`): `Vertical` は 2 列 × 5 行の 10 枠が全部見える (`...` なし)。左上。インベントリの格子と `+` は、下の段 (スティックの右) に移る。
- **名前の消える時間** (設定 `tooltip_fade`、0〜15 秒、既定 1): 枠を選んだとき、選んだアイテムの名前を出し、時間が来たら消す。0 のときは出さない。
- **体力・マナの数値**: ハート・星をタップすると、数値 (`現在/最大`) を 3 秒出す。使った・回復中にも出す。
- **投げる**: ホットバーの枠から、枠 1.5 個分以上、外へドラッグして離すと、そのアイテムを**スタックごと**、プレイヤーの頭の位置に落とす ([仕様 10 §19](10-noita-like-game.md))。お気に入り (§10) は投げない。

### テスト

| テスト | 確認 |
|---|---|
| `hotbar_vertical_layout_fits_without_overlap` | 縦型は 10 枠が収まり、部品と重ならない (3 つの画面の大きさ) |
| `hotbar_orientation_setting_roundtrips` | 保存・読み込み、既定 |
| `tooltip_fade_shows_then_hides_the_item_name` | 時間で消える。0 は出さない |
| `tapping_hearts_shows_numbers_for_three_seconds` | 数値の表示と時間 |
| `dragging_a_hotbar_slot_outside_drops_the_stack` | 外へ離すと全数が落ちる。近いままなら選ぶだけ |

## 10. T34.6 インベントリの下のボタン

### 規則

- 持ち物の画面の下に、次のボタンを出す。選んだアイテムが対象のものは、アイテムを選ぶまで無効 (暗い)。
  - **Use**: 選んだアイテムを、ホットバーの枠へ印して選ぶ (使うときのカーソルは世界の指・スティック)。
  - **Favorite / Unfavorite**: お気に入りにする・外す。お気に入りは、投げる・ゴミ箱・クイックスタックの対象外。枠に縁を付ける。保存する (`game.ron`、名前で)。
  - **Quick Stack**: 届く範囲 (半径 37.5 タイル = 300 セル) の有効な**箱**のうち、同じアイテムが入っている箱へ、持ち物の同じアイテムを全部移す。複数の箱にあれば、**世界の中で低い (y が大きい) 箱**へ。お気に入りと装備中は移さない。箱を開いているときは、その箱だけ。
  - **ゴミ箱** (1 枠): アイテムをドラッグして入れると、**全数が消える**。前に入っていたものは**戻らず消える**。死ぬ・世界を出ると空。お気に入りは入れられない。
- 持ち物は種類ごとの個数なので、**分割 (Split) と並べ替え (Sort) は作らない** (§3)。
