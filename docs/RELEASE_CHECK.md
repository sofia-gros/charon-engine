# 第5段階の配布前確認 (2026-11-15)

**結論: 製品版としてリリース可とは判定しない。** 以下の自動検査は、T33.5 のヘッドレス検査 (設定・世界・プレイヤーの保存と、アセットごとの出所記録) と、M34 (v0.1.0) の操作のヘッドレステスト (`terraria_android_controls_chain` ほか [仕様 28](spec/28-terraria-android-controls.md) の表のテスト) に限る。**指で触れた実機での操作感・実機の Terraria との並べた比較は未実施**。配布への判断には下記の未検証事項が残る。2026-11-15 に v0.0.8 のプレリリース公開を依頼されたが、Android の `cargo-apk` が明示版数を拒否してビルドが失敗し、Release は公開されなかった。既存の失敗タグは動かさず、依頼者の選択で v0.0.9 を新しいタグとしてビルドする。この記録と自動検査は実機・署名・権利を承認するものではない。公開結果は GitHub Releases で別途確認する。

- `experience_reload_retains_settings_and_progress`: seed 1..=8 の別 App で `settings.ron` と世界/プレイヤーの保存を読み込み、言語、音量、光、更新距離、キー設定、セル、持ち物・ホットバー・装備、領域・製作・ボスの進行を比較する。実画面での再起動ではない。
- `bundled_assets_have_a_recorded_origin`: [出所記録](ASSET_ORIGINS.md) と `assets/` の全ファイルを一対一で照合し、OFL 原文の存在を確認する。ファイルの合法性や個々の権利者の同意を判定しない。
- `scripts/check.sh`: fmt、両 feature の clippy/テスト、ドキュメント、Android/WASM の型検査を実行する。結果はタスクのコミット/CI に記録する。Android アプリの実行は含まない。

## 権利と配布物 (未検証)

- リポジトリのコードは [MIT](../LICENSE) と表示している。`assets/` は [出所記録](ASSET_ORIGINS.md) に全ファイルを列記したが、ゲーム素材の配布条件は未決。フォントは Google Fonts の Noto Sans JP と同じディレクトリの SIL OFL 1.1 原文を保持している。著作権表示、原本との同一性、APK 内の表示方法は最終確認が必要。
- 2026-11-15、`cargo metadata --locked --offline --format-version 1` の全ターゲットを含む解決集合には、ワークスペース外の **457 パッケージ**があり、`license` フィールドの空欄は **0**。MIT/Apache-2.0 以外にも Unicode-3.0、OFL-1.1、Ubuntu-font-1.0、Zlib、BSD、MPL、LGPL/GPL を選べる式などが申告されている。これは Windows/Android の各配布バイナリに実際に含まれるものの一覧ではなく、ライセンス文・NOTICE・再配布条件を精査した結果でもない。`Cargo.lock` を出発点に `cargo deny` / `cargo about` 等で対象ごとの実際のライセンスと通知文を生成・確認し、`THIRD_PARTY_LICENSES` を作る作業が残る。
- `.github/workflows/release.yml` の Windows zip は exe、`assets/`、`LICENSE`、`README.md` のみを同梱し、`THIRD_PARTY_LICENSES` はまだない。Android APK はフォントとデモ MOD の一部を埋め込むが、OFL の原文と第三者通知が実際の APK 内から確認できるかは未検証。権利一覧を作っただけで通知義務を満たしたとはしない。
- CI の Android `--release` は `apps/sandbox/debug.keystore` をその場で作り、パスワード `android` のデバッグ鍵で署名する。毎回異なる鍵になるため、v0.0.9 以前の APK から v0.1.0 への上書き更新はできない。再インストール時に保存データが失われる可能性がある。本番の安全な鍵の作成・保管・更新経路と Windows コード署名は未実施。署名済みの製品版とみなさない。
