# ゲームエンジンとして必要なこと (一覧と現状)

落下砂のゲーム (Noita・Terraria 型) を、**エンジンとゲームを分けて**作るために必要なものを、領域ごとにまとめた。
状態は、**✅ 実装・自動テスト済み**、**🟡 一部だけ** (できないことを書く)、**❌ 未着手** の 3 つ。
「実機で確認したか」は別の軸で、[PLATFORM_CHECK](PLATFORM_CHECK.md) と [STATUS](STATUS.md) に分けて書く。
完了していないものを完了とは書かない。

## 1. シミュレーション (セルの世界)

| 必要なこと | 状態 | 備考 |
|---|---|---|
| 粉体・液体・気体の移動、密度、摩擦、粘性 | ✅ | M1 |
| 反応・熱・相変化・燃焼・寿命 | ✅ | M2。材質と反応は RON |
| 決定性 (同じ seed と入力なら同じ結果)、乱数は `rng::hash` だけ | ✅ | 浮動小数点はコアに使わない。異種 OS 間の一致は未検証 |
| 休眠 (動かない領域は何もしない) | ✅ | |
| 更新範囲 (カメラの周りだけ動かす、Terraria と同じ) | ✅ | T9.7。範囲の外は保留して、入ったら処理 |
| 並列化 (`unsafe` なし) | ✅ | 9 フェーズ |
| 性能目標 (100 万セルを 8 ms) | 🟡 | 約 35〜41 ms。未達。休眠 1 万チャンクは達成 |
| 電気・電線・ガスの圧力・流体の圧力など、追加の物理 | ❌ | 材質と反応の RON で足せる範囲の外 |
| 地形の崩落 (支えのない固体が落ちる) | ✅ | T16.4。掘ったあとに、つながった固体をひとかたまりで落とす ([仕様 10 §16](spec/10-noita-like-game.md))。見た目の確認は未 |
| 問い合わせ (raycast・視線・円の検索) | ✅ | T16.1。[仕様 01 §7](spec/01-core-data.md)。エンティティの検索は ❌ |

## 優先して足すもの (提案)

1. **アニメーション (スプライトシート)** と、敵・アイテムへの画像の割り当て — 静止画の画像と `scale` は M14 で入った。次は動かす。画像・UI は**どれも大きさを倍率で決められる**ことを原則にする (今は `scale`・`UI scale`)。
2. ~~地形の崩落と浮遊~~ — M16・M17 で入った (見た目・手触りは未確認)。
3. **装備品・アイテムの種類と、持ち物の画面の操作** — 持ち物・ドロップ・保存は入った。次は、材質以外のアイテム。
4. ~~音声デバイスへの出力~~ — `cpal` で実装済み。残りは BGM・空間音・圧縮形式。
5. ~~ゲーム用 UI と設定・キー割り当て~~ — M15 で入った (見た目の作り込みとゲームパッドで操作するメニューは残り)。
6. **Android・Linux・Web の実機確認と、ゲームパッドの実機確認** — 未検証のまま「対応」と言わない。
7. **通信のアプリへの組み込み** — ホスト中継の TCP (標準ライブラリだけ) は M15 で入った ([仕様 13](spec/13-network.md))。次は、メニューの `Host`・`Join`、遅延の補正、途中参加。
8. **性能 (100 万セル 8 ms)** — 未達 (約 4.4 倍)。更新範囲の限定と、液体・気体の確認の省略 (T17.8) は入った。次は実際のゲームのフレーム時間を測る。

この一覧は、実装が進むたびに状態を直す。タスクと完了条件は [ROADMAP](ROADMAP.md)。
