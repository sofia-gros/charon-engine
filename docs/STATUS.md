## 確認の範囲

- **Windows (Ryzen 7 2700 / RTX 4060, Vulkan):** サンドボックスとデモの起動を確認。オフスクリーン描画で各場面を確認。2026-11-12 に利用者が実機で試し、速度は十分で、光を有効にしたときの重さと遠くの砂・水の計算が見つかった (M12 で対応)。
- **Linux:** `charon-demo` をウィンドウで起動して確認した記録がある ([PLATFORM_CHECK](PLATFORM_CHECK.md))。
- **Web:** wasm ビルドと、実ブラウザーでの起動・描画ループのスモークテスト。ブラウザー上の保存・操作は未検証。
- **macOS・Android 実機:** 未検証 (Android は型検査まで)。

## 性能の目標と実測

M9 の最終再計測 (Ryzen 7 2700 / Windows 11) は、並列で動く砂 1,048,576 個を **84.509 ms/tick**、休眠 10,000 チャンクを **43.415 µs/tick** でした。その後 T9.6 で約 35〜41 ms/tick になりました。デスクトップ 8 ms 目標は未達です。条件と全場面の履歴は [BENCHMARKS](BENCHMARKS.md) を参照してください。

| 環境 | 目標 |
|---|---|
| デスクトップ (8 コア) | 動いているセル 100 万個の 1 tick を 8 ms 以内 |
| Android (高性能 4 コア) | 動いているセル 25 万個の 1 tick を 8 ms 以内 |
| 休眠した領域 | コストほぼ 0 |

## 開発環境の補足

- **Linux でウィンドウを開く場合:** `libxkbcommon-x11` (Debian / Ubuntu では `libxkbcommon-x11-0`) が必要です。ない環境では起動直後に `Library libxkbcommon-x11.so could not be loaded.` で panic します。
- **GPU のない Linux:** `mesa-vulkan-drivers` (lavapipe) を入れ、`VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/lvp_icd.json` を指定します (物理 GPU の検証にはなりません)。Chromium 同梱の SwiftShader はオフスクリーンの描画テストには使えますが、ウィンドウには対応しません。
- **Web:** `wasm-bindgen-cli` が必要です。`Cargo.lock` の `wasm-bindgen` と同じ版 (現在は 0.2.130) を入れます。実ブラウザーのスモークテストは `node tools/web-smoke/smoke.js` (Playwright と Chromium が必要。リポジトリの依存ではありません)。WebGPU のキャンバスへの描画は、ヘッドレスの Chromium ではデバイスが破棄されるため対象外です。
- **移動規則の試作:** `python3 tools/prototype/run.py` で、液体と粉体の規則が「必ず止まる」「水面が平らになる」ことを確かめられます。
