# Android 版 Terraria の操作方法と GUI — 調査資料

調査日: 2026-11-15。対象: Android (Google Play) 版 Terraria **1.4.5.8.1 (Build 1720、2026-09-17 配信、PC 版 1.4.5.8 相当)**。
iOS・Amazon 版も同じ系統で、操作と GUI は共通です。

## 0. この資料の読み方と限界

**先に結論**: 公開されている公式資料から分かることは、ほぼ全部ここにまとめました。ただし「GUI のすべての動作・形・見た目」を**完璧に**確定させることは、公開資料だけではできません。実機の Terraria を動かして確認していないためです。分かっていない点は、隠さずに §12 に一覧にしました。

### 調べ方

- 公式 Terraria Wiki (terraria.wiki.gg) の本文と掲載画像。
- 公式フォーラム (forums.terraria.org) の開発元の告知と操作解説。
- 日本語の攻略 Wiki (Switch / PS4 / iOS / Android 共通)。
- このリポジトリにある、持ち主が実機で確認した記録 ([仕様 18](spec/18-terraria-touch.md) §5)。

**実機の Android 版 Terraria は操作していません。** 動画も見ていません (音・動きの速さ・アニメーションは確認できていません)。

## 1. 全体像

### 1.1 入力の種類

| 入力 | 状況 |
|---|---|
| タッチ (仮想スティックとボタン、画面の直接タップ) | 標準。この資料の中心 |
| コントローラー (Bluetooth の Xbox One / PS4 など) | 1.3.0.7.8 (2020-04) から対応。割り当ては設定で変更できる 【公式】 |
| キーボードとマウス | 2022 年の更新から正式対応。入力方式が勝手に切り替わり続けないよう「入力ロック」がある 【Wiki】 |

Wiki の「モバイル版」ページには「キーボードとマウスの基本操作はできるが、タッチ UI は消せず、キーの割り当ても変えられない」とあります。一方で設定の表には「Keyboard & Mouse」のキー割り当てメニューがあります。**この 2 つは食い違っており、どちらが現行版か未確認です** 【未確認】。

### 1.2 画面の構成

画面は、大きく 4 つの層でできています。

1. **ゲームの世界** (全面)。
2. **HUD** (常に出ている情報): ホットバー、体力、マナ、バフ、ミニマップ、情報の文字、右上の小さなボタン。
3. **仮想コントロール** (下の左右): スティックとボタン。位置・大きさ・種類は自由に変えられる。
4. **ページ群** (インベントリを開いたとき): 左上にインベントリのページ群、右上に装備・クラフト・チャットなどのページ群。ページ群の場所と中身も設定で変えられる。

仮想コントロールとページ群は、どちらも**利用者が編集できる**のが Terraria モバイル版の大きな特徴です。そのため「正しい配置」は 1 つではなく、**既定の配置**と**利用者ごとの配置**を分けて考える必要があります (§10)。

## 2. 通常画面の HUD

位置は、公式の配置図 (2019 年、1.3.0.7、4:3 の画面 2048×1536) から目測した値です。`x%` は画面の幅、`y%` は高さに対する割合で、**誤差は ±1.5% 程度**あります。横長のスマホでは、部品は左右の端と四隅を基準に置かれるので、中央の空きが広がります 【画像】。

### 2.1 ホットバー

| 項目 | 内容 | 根拠 |
|---|---|---|
| 場所 | 左上の隅 | 【画像】 |
| 形 (**モバイルの既定**) | **縦型: 2 列 × 5 行** の 10 枠 | 【Wiki】設定「Hotbar Orientation」既定 = Vertical |
| 形 (切り替え後) | 横型: 1 行 × 10 枠 | 【Wiki】 |
| 枠の大きさ (縦型) | 1 枠 ≈ 幅の 4.5%。2 列で x 0.5〜9.5%、5 行で y 0.7〜31% | 【画像】 |
| 枠の見た目 | 角の丸い四角。半透明の濃い青。アイテムの絵と、右下に個数の数字 | 【画像】 |
| 選択中の枠 | **黄色**で塗られる | 【画像】 |
| タップ | その枠を選ぶ。**消耗品なら、すぐに使う** | 【Wiki】 |
| ドラッグ | 枠からアイテムを外へ引きずると、その方向へ数ブロック先に**スタックごと投げる** | 【Wiki】 |
| 選んだアイテムの名前 | 選んだ直後に表示され、時間で消える。消えるまでの時間は設定「Tooltip Fade」(0〜15 秒、既定 1 秒) | 【Wiki】 |
| オートセレクトの枠 | オートセレクトで選ばれたアイテムが、ホットバーの**追加の枠**に出る | 【Wiki】 |
| 切り替え中の印 (1.4.5) | アイテムを使っている最中に別の枠を選ぶと、使い終わるまで小さな「入れ替え」の印が出る | 【Wiki】 |

持ち主の実機では**横一列**で、見える枠が 5 つ + `...` でした 【持ち主】。これは設定を横型にした状態と考えられますが、「5 つ + `...`」という畳み方は公開資料に記述がありません 【未確認】。

### 2.2 体力とマナ

| 項目 | 内容 | 根拠 |
|---|---|---|
| 場所 | 体力は右上。マナは右端に縦 1 列 | 【画像】 |
| 単位 | ハート 1 個 = 体力 20。星 1 個 = マナ 20 | 【Wiki】(ゲームの共通仕様) |
| 見た目の種類 | 設定「Health and Mana Style」: **Classic / Fancy / Bars**。既定は **Fancy** | 【Wiki】 |
| 数字 | ハートや星を**タップすると数値が出る**。使ったとき・回復中にも出る | 【公式】 |
| 配置図での位置 | ハートの行は y ≈ 2%、x 73〜91%。左に `Life` の文字と `192/300` の数字。星は x ≈ 98%、y 12〜36% に縦 10 個 | 【画像】 |

3 種類の見た目の細部 (枠の形、色、ハートが 2 段になる条件、金色のハートの出方) は、公開資料に文章での説明がありません 【未確認】。

### 2.3 バフ・デバフ

- ホットバーの下に、小さなアイコンと残り時間が並ぶ 【Wiki】。
- 同時に持てるのは 44 個まで 【Wiki】。
- **解除**: アイコンをタップして選び (強調される)、もう一度**ダブルタップ**で消す 【公式】。
- アイコンの大きさ、並ぶ列の数、折り返しの位置は 【未確認】。

### 2.4 ミニマップと情報の文字

| 項目 | 内容 | 根拠 |
|---|---|---|
| ミニマップ | 右上、ハートの下。四角い枠。既定で表示 | 【Wiki】【画像】 |
| 大きさ | 設定「Minimap Size」: Small / Large。**モバイルの既定は Small** | 【Wiki】 |
| 配置図での位置 | x 79.6〜95.6%、y 7〜25% (幅の約 16%、高さの約 18%) | 【画像】 |
| 枠の見た目 | 設定「Minimap Border」で 9 種類から選ぶ (Default、Valkyrie、Retro、Leaf、Twig Leaf、Stone Gold、Sticks、Remix、Golden)。見た目だけの違い | 【Wiki】 |
| 表示の切り替えボタン | ミニマップの右上の小さな四角いボタン。**枠の種類に合わせてボタンの絵も変わる** | 【Wiki】 |
| 情報の文字 | ミニマップの**左**に、右揃えで縦に並ぶ (時刻、天気、釣り、位置など)。各行の右に小さなアイコン | 【画像】 |
| 設定で消す | 設定「Map」を Off にするとミニマップが出ない。タイトル画面でしか変えられない。メモリーの少ない端末では常に Off | 【Wiki】 |

### 2.5 右上の小さなボタン

配置図 (1.3.0.7) では、右上に四角い小さなボタンが並びます 【画像】。

| ボタン | 位置 (目測) | 動き |
|---|---|---|
| チュートリアル (電球) | x ≈ 93.5%、y ≈ 3% | 1 人プレイで押すと、各部品をタップして説明を読める。マルチプレイでは同じ場所が**チャットの表示切り替え**になる |
| マップを開く | x ≈ 97.8%、y ≈ 3% | 全画面マップを開く。もう一度で閉じる |
| ミニマップの表示切り替え | x ≈ 97.8%、y ≈ 8.7% | ミニマップを隠す・出す |

2022 年の画像 (1.4 系) では、右上のボタンは「チャット」「マップ」「ミニマップ」の 3 つが横に並び、その下にマナの星があります 【画像】。

| 部品 | 内容 | 根拠 |

| イベントの進行バー | 設定「Event Progress Bar」: Off / Timed / On (既定 On)。Timed は、しばらく敵を倒さないと隠れる | 【Wiki】 |

| 拾ったものの文字 | 拾うとプレイヤーの上に名前が浮かぶ。設定「Pickup Text」で消せる | 【Wiki】 |

| コントローラーのヒント | コントローラー使用時に、ボタンの案内が出る。1.4.5 から、画面の下にまとめず、**関係する部品の近く** (ページの中、アイコンの中、HUD の中) に出る | 【公式】 |

### 3.2 1.4.5 の変化 (現行版)

1.4.5 (2026-01) で、操作まわりが大きく変わりました 【公式】。

| 追加・変更 | 内容 |
|---|---|
| **ラジアルボタン** | 1 つのボタンに**最大 4 つの動作**をまとめる。**押して、その方向へスワイプ**すると、その動作が出る。使うかどうかは自由 |
| **操作エディタの作り直し** | 部品の**種類** (スティック / ボタン / ラジアル) を先に選んで置き、あとから動作と大きさを決める。エディタの中で試せる |
| **新しい既定のプリセット** | エディタに「New Default」などのプリセットがある。**右のスティックをなくす**方式も選べる |
| **マルチタッチ** | ボタンごとの設定。On のボタンは、指をボタンの外へ滑らせても**押されたまま**。その指を別のマルチタッチのボタンの上へ動かすと、**そのボタンも押される** (指が上にある間だけ)。指を画面から離すと両方とも離れる |
| **主・副アクションの切り替え** | インタラクトのボタンが**切り替えスイッチ**になった。押すと、ボタン・スティック・画面のタップの**すべて**が、主アクションと副アクションのどちらを出すかが変わる |
| **近接インタラクト** | 動いておらず、狙ってもおらず、カーソルが別の対象の上にないとき、インタラクトを押すと**足元にあるもの**が対象になる |
| コピーと貼り付け | 操作の設定を、プロファイルの間でコピーできる |

公式 Wiki の 1.4.5 のエディタ画面では、次の配置が写っています 【画像】。

- 左: インタラクトのボタン、移動スティック、**ラジアルボタン** (クイックマナ・クイックバフ・クイック回復を 1 つにまとめたもの。中央が黄色い円で、まわりに 1〜4 の番号と各アイコン)。
- 右: フック (緑)、マウント (緑)、ジャンプ、エイムスティック (`+`)。
- 下: ズームのボタン。

これが「New Default」の実際の配置かどうか、全部の部品が写っているかは、この 1 枚の画像からは断定できません 【未確認】。持ち主が実機で見た配置 ([仕様 18](spec/18-terraria-touch.md) §1: 左下に格子と `+`、右下に大きな `+` の円、その左にフック、下の中央に虫めがね 2 つ) は、この 1.4.5 の配置と矛盾しません。

## 4. 操作のしくみ

### 4.1 移動スティック (左)

| 入力 | 動き | 根拠 |
|---|---|---|
| 左右へ倒す | 歩く。倒している間ずっと動く | 【公式】 |
| 上へ倒す | ロープを登る、足場に乗る、重力の反転 (薬)、落下を遅くする (薬) | 【Wiki】 |
| 下へ倒す | 足場から降りる、ロープを降りる、水に潜る (水上歩行のとき) | 【Wiki】 |
| 上へ**ダブルタップ** (既定) | **ジャンプ**。そのまま押し続けると飛ぶ (翼) | 【公式】【Wiki】 |
| 下へダブルタップ | 一部の防具のセット能力を発動 | 【公式】 |
| 左右へダブルタップ | ダッシュ (対応する装備があるとき) | 【公式】 |
| ジャンプボタンのあと、下 + ジャンプを押し続ける | **ホバー**。スティックを左下・右下へ滑らせると横に動く | 【公式】 |
| 飛行の中断と再開 | 飛んでいる途中でスティックを左右や下へ動かすと一時的に止まり、また上へ滑らせると飛行を再開 | 【Wiki】 |

**ジャンプの方式は設定で選ぶ** (§7.5「Up To Jump」)。モバイルの既定は「ダブルタップ」です 【Wiki】。

- ダブルタップ: 上を 2 回たたくとジャンプ。
- シングルタップ: 上へ倒すだけでジャンプ。
- スワイプ: 上へはじくとジャンプ (1.2 の旧操作と同じ)。
- 無効: スティックではジャンプしない。

持ち主の実機では「左スティックの上ではジャンプしない」でした 【持ち主】。これは**設定を「無効」にした状態**、または「ダブルタップ」のまま 1 回だけ倒した状態と考えられます。既定の動きとは区別してください。

**スマートカーソルがオンのとき**、移動スティックの向きにカーソルも向きます (エイムスティックを使っている間はそちらが優先)。設定「Movement Stick Aim」で切れます 【公式】【Wiki】。

### 4.2 ジャンプボタン

- 押すとジャンプ。**押し続けると高く跳ぶ** 【公式】。
- 空中で離してもう一度押すと、二段ジャンプ (雲のビンなど) 【公式】。
- 翼があれば、押し続けると飛ぶ 【公式】。
- 水中で繰り返し押すと泳いで上がる (対応する装備があるとき) 【Wiki】。

### 4.3 エイムスティック (右) と、狙う方式の切り替え

エイムスティックを動かすと、カーソルがその向きに動きます 【公式】。そのとき**アイテムも使うかどうか**を、切り替えボタンで決めます。

| 方式 | 動き |
|---|---|
| **Aim & Use** (狙って使う) | スティックを倒している間、狙いながら使い続ける。連射できる武器に向く |
| **Aim Only** (狙うだけ) | スティックはカーソルを動かすだけ。使うのは「サブ攻撃」などのボタンで行う。細かい建築に向く |

細かい決まり 【公式】:

- **アイテムごとに方式を覚える**。剣は「狙って使う」、ブロックは「狙うだけ」のように、選ぶアイテムを変えると切り替えボタンの状態も変わる。
- 一部のアイテムは、スティックの**中心をたたいただけ** (倒していない) では、すぐには使われない。狙う間を少し置くためで、誤操作を防ぐ。
- 設定の「Aim Mode Toggle」で、切り替えの単位を変えられる (§7.6)。既定は「アイテムの種類ごと」。
- 設定の「Aim Sensitivity」(50〜150%) で、スティックの感度を変えられる。

カーソルがスティックの倒し方に対してどれだけ動くか (倒した量と距離の関係、届く範囲の縁での止まり方) は、公開資料に数値がありません 【未確認】。持ち主の確認では、スマートカーソルがオフなら**倒した量に応じて円の中を動き**、オンなら**倒した向きの円の縁へすぐに動く**とのことです 【持ち主】。

### 4.4 サブ攻撃ボタン (Secondary Fire / Action)

- 選んでいる道具・武器を使うだけのボタン。ほかの働きはない 【公式】。
- 「狙うだけ」方式のときの、主な使う手段。
- 連射できない武器は、このボタンを繰り返したたいて使う。
- ロックオン中は、このボタンで対象へ向けて自動で撃つ。

### 4.5 スマートカーソルとオートセレクト

**スマートカーソル** (切り替えボタン): 選んでいるアイテムに合わせて、対象を自動で選びます 【Wiki】【公式】。

| 選んでいるもの | 動き |
|---|---|
| つるはし | カーソルの向きに、通れる幅の通路を掘る。縦に掘るときの幅は 2 タイル |
| 斧 | カーソルに近い木の根元を切る。根元に届かなければ枝 |
| ハンマー | カーソルに近い壁を壊す |
| ブロック | カーソルに近い、置ける場所に置く。**モバイルではあまり当てにならない**と Wiki に書いてある |
| 壁 | プレイヤーから見通せる範囲で、近い場所に置く (部屋の外へはみ出さない) |
| 足場 | 今ある足場を延ばす (縦も可) |
| レール | 今あるレールを横や斜めに延ばす |
| 配線の道具 | 同じ色の配線を延ばす、または近い配線を外す |
| どんぐり | 草の上の、間隔の合う場所に植える |

- つるはしと斧を兼ねる道具は、**斧として動く** (届く範囲に木があれば、木を先に狙う)。設定「Smart Cursor Priority」で優先を変えられる。
- **アイテムごとにオン・オフを覚える** 【公式】。
- 設定「Smart Block Placement」が On だと、ブロックを、スマートカーソルの対象からカーソルの位置へ向けて置いていく 【Wiki】。

**オートセレクト** (ボタン): カーソルの下にあるものに合う道具を、自動で選びます。ホットバーに入っていなくてもよい 【公式】【Wiki】。

| カーソルの下 | 選ばれるもの |
|---|---|
| ブロック、たいていの家具 | つるはし |
| 木、きのこの大木、サボテン | 斧 |
| 祭壇、オーブ | ハンマー |
| 何もない場所・壁 | 明かり (たいまつ。遠ければ光る棒。水中では水中で使える明かり) |

- 既定は「**押している間だけ**」有効 (設定「Auto Select Mode」: Hold / Toggle) 【Wiki】。
- 押している間、エイムスティックや画面のタップで、ボタンに出ているアイコンの動作をする 【公式】。

### 4.6 スマートインタラクト / アクションの切り替え

**1.3〜1.4 系**: カーソルの下にあるものに応じて働きが変わるボタン 【公式】。

- カーソルの下に何もなければ、ほかのアクションボタンと同じく、選んだアイテムを使う。
- NPC・宝箱・ドアなどの上なら、話す・開けるになる。
- つるはしを持っていると、つるはしが優先されることが多い (ゲームが「取り除きたい」と判断するため)。

**1.4.5 から**: このボタンは**主・副アクションの切り替えスイッチ**になり、近接インタラクトが加わりました (§3.2) 【公式】。

### 4.7 フックのスティック

| 入力 | 動き | 根拠 |
|---|---|---|
| ある方向へ**スワイプ** | その向きへフックを飛ばす | 【公式】 |
| スティックの**縁をタップ** | その向きへすばやく飛ばす | 【公式】 |
| 続けて操作 | フックが複数出る種類では、押すたびに次のフックが出る。全部がリセットされるまで (ジャンプなど) | 【公式】 |
| フックを持っていない | ボタンが灰色 | 【公式】 |

フックをホットバーに入れて選び、エイムスティックで使うこともできます 【公式】。

持ち主の確認では「傾けて**離した向き**へ飛ぶ」「傾けている間は向きの矢印が出る」でした 【持ち主】。公式の説明は「スワイプした向き」で、矢印には触れていません。**飛ぶ瞬間が「倒したとき」か「離したとき」か、矢印の形**は資料から確定できません 【未確認】。

### 4.8 マウントのボタン

- 押すと乗る・降りる。トロッコからも降りられる 【公式】。
- 装備の枠のマウントを優先する。なければインベントリのものを使う 【公式】。
- マウントがなければ灰色 【公式】。

### 4.9 クイック回復・クイックマナ・クイックバフ

| ボタン | 動き | 根拠 |
|---|---|---|
| クイック回復 | 体力を満タンにできるアイテムのうち、**いちばん弱いもの**を使う (むだを減らす)。使われるアイテムがボタンの中に表示される | 【公式】 |
| クイックマナ | インベントリの左上から最初に見つかったマナ回復を使う | 【Wiki】 |
| クイックバフ | 持っているバフの薬と食べ物を、種類ごとに 1 つずつ使う。すでに効いているものは使わない | 【公式】【Wiki】 |

薬がない・待ち時間中・満タンのときは灰色 【公式】。

### 4.10 ロックオン (Combat Targeting)

- 狙える敵には小さな黄色い三角が出る。ロックオンのボタンを押すと固定する 【公式】。
- 固定中は、対象のまわりに黄色い矢印が 3 つ出て、攻撃がそこへ向く 【Wiki】。
- もう一度押すと、解除または別の対象へ切り替え 【Wiki】。
- 設定「Lock On Priority」: **Clearest Line** (見通せる敵を優先。既定) / **Target Closest** (いちばん近い敵) 【Wiki】。
- 撃った時点の敵の位置へ撃つだけなので、速い敵や遅い弾では外れる 【Wiki】。
- 敵が無敵になる・当たり判定が消えると、自動で外れることが多い 【Wiki】。
- 1.2 までは自動でロックオンしたが、1.3.0.7 でなくなった 【Wiki】。

### 4.11 ズームとマップ

| 入力 | 動き | 根拠 |
|---|---|---|
| ズームのボタン (2 つ) | 押すと拡大・縮小。**ボタンではマップは開かない** | 【公式】 |
| ピンチ | 拡大・縮小 (設定「Pinch Zoom World」) | 【公式】【Wiki】 |
| いちばん縮小した状態から、さらにピンチ | **全画面マップに切り替わる** (設定「Pinch Zoom Map」)。マップで拡大していくと、ゲーム画面に戻る | 【公式】【Wiki】 |
| 最大のズーム | ×2.00 | 【Wiki】 |

注意: ピンチを始めるときに画面に触れるので、**持っているアイテムを使ってしまう**ことがある (つるはしで物を壊すなど) 【公式】。

持ち主の実機では、ズームのボタンを「押している間、滑らかに拡大・縮小」でした 【持ち主】。

### 4.12 画面の直接タップ

**ゲームの世界を指で直接さわっても、スティックと同じ操作ができます。** ブロックの配置もできます。公式の解説は、これを「Tapping in the World (タッチ操作)」と呼び、エイムスティックの**代わりに使える手段**と説明しています 【公式】。公式 Wiki の入門ガイドにも「右のスティックでアイテムを使う。代わりに、**画面のどこでもタップして、アイテムを使う・ブロックを置く**こともできる」とあります 【Wiki】。持ち主も「ワールドの場所をタッチしてブロックを配置できた」と確認しています 【持ち主】(2026-11-15)。

開発元の考え方 【公式】:

- スティックだけでも、タップだけでも、**全部の操作ができる**。
- 場面によって、スティックのほうがよいことも、直接タップのほうがよいこともある。多くの人は、**両方を混ぜて使う**ようになる。それが狙いどおりの遊び方。

#### 4.12.1 世界をさわる操作

| 指の動き | 起きること | 根拠 |
|---|---|---|
| 世界の 1 点を**タップ** | 選んでいるアイテムを、**その場所に向けて使う**。ブロック・壁・家具なら**その場所に置く**。つるはしなら掘る。斧なら切る。武器ならその向きへ振る・撃つ | 【公式】【Wiki】【持ち主】 |
| **タップして押し続ける** | 武器を振り続ける・撃ち続ける | 【Wiki】 |
| 消耗品を選んで**タップ** | 薬を飲む。マウントや召喚のアイテムを使う | 【Wiki】 |
| ドア・宝箱・スイッチ・看板・NPC を**タップ** | 開ける・切り替える・読む・話す (インタラクト) | 【公式】【Wiki】 |
| オートセレクトのボタンを**押しながら**、世界をタップ | ボタンに出ている道具で、その場所に作業する (たいまつを置く、掘るなど) | 【公式】 |
| 2 本の指で**ピンチ** | 拡大・縮小。いちばん縮小した先は全画面マップ (§4.11) | 【公式】 |
| タイトル画面の太陽・月を**ドラッグ** | 太陽・月が動く。背景も左右に動く | 【Wiki】 |

**決まりと注意**

- **届く範囲の中でないと働かない**。画面の反対側の NPC とは話せない 【公式】。置ける距離・壊せる距離は、アイテムと装備で変わる (道具箱やはしごなどで伸びる)。インタラクトできる距離も、置ける距離に従う 【Wiki】。
- ブロックは、**ほかのブロックに隣り合う場所**でないと置けない (置いたあとは、支えがなくても浮いたまま) 【Wiki】。
- **つるはしを持っていると、物を「取り除く」ほうが優先されやすい**。宝箱や家具を開けるつもりで、壊してしまうことがある 【公式】(スマートインタラクトの説明)。
- **ピンチを始める指が、アイテムを使ってしまう**ことがある。つるはしを持ったまま、大事な物の近くでピンチしない 【公式】。
- ロックオン中でも、ブロックを置ける (1.4.0.5.2 で直った) 【Wiki】。
- 1.4.5 の**主・副アクションの切り替え**は、画面のタップにも効く。副アクションに切り替えると、タップでも副アクションが出る 【公式】。

**置くときの補助の表示** (設定で切り替え。§7.5、§7.6)

| 表示 | 内容 | 根拠 |
|---|---|---|
| 拡大鏡 (Magnifier) | タイルを置くとき、カーソルの近くを**拡大した小窓**が出る。指で隠れる場所を見るためのもの。既定で On | 【Wiki】 |
| タイルのグリッド | 止まっているとき、カーソルのまわりに 5 タイル幅の格子 | 【Wiki】 |
| 配置のプレビュー | 家具を、置く前に実際の大きさで表示 | 【Wiki】 |
| タッチのカーソル | タッチで操作しているときも、カーソルが表示される。色は設定「Touch Cursor Color」で変えられる | 【Wiki】 |
| 定規 | プレイヤーからカーソルまでの測定線 (ツールで On) | 【Wiki】 |

拡大鏡は 2013 年の最初の版からある機能で、当時の更新履歴に「拡大鏡は常に画面の中にとどまり、必要なら横へよける」とあります 【Wiki】(旧版の記述。現行版で同じかは未確認)。

**分かっていないこと** 【未確認】

- 指を**押したまま動かしたとき**、置く場所・掘る場所が指に付いてくるか (なぞって連続で置けるか)。
- スマートカーソルがオンのとき、タップした場所がどう補正されるか。
- タップしたあと、カーソルがその場所に残るか、どのくらいで消えるか。
- 敵をタップしてロックオンの対象を変えられるか (1.2 までの自動ロックオンではできた。現行版は不明)。
- 仮想コントロールの上や近くをさわったとき、世界へのタップとどちらが優先されるか。
- 拡大鏡の大きさ・位置・倍率。

#### 4.12.2 HUD をさわる操作

| ホットバーの枠を**タップ** | その枠を選ぶ。消耗品なら、すぐに使う | 【Wiki】 |

Switch 版 (携帯モード) には「ホットバーを**ダブルタップ**でインベントリを開く」「ミニマップを**タップ**で全画面マップ」があります 【Wiki】。モバイル版で同じ操作ができるかは書かれていません 【未確認】。

#### 4.12.3 インベントリの中をさわる操作

| 指の動き | 起きること | 根拠 |
|---|---|---|
| 枠を**タップ** | 選ぶ。下のボタン (Use、Favorite、Split など) の対象になる | 【Wiki】 |

| Craft を**押し続ける** | 続けて作る (だんだん速くなる) | 【Wiki】 |

装備の枠を**ダブルタップ**しても、表示の切り替えにはなりません (Switch 版ではなる) 【Wiki】。

#### 4.12.4 仮想コントロールをさわる操作 (まとめ)

| 指の動き | 起きること | 参照 |

#### 4.12.5 Charon の方針との関係

[仕様 18](spec/18-terraria-touch.md) §2 は、2026-11-13 の確認をもとに「画面を直接タップしてカーソルを置く方式は**作らない**」と決めています。しかし**Terraria 本体には直接タップがあり、ブロックも置けます**。持ち主の 2026-11-15 の指摘とも合います。「Android 版と同じ操作」を目標にするなら、仕様 18 のこの決定は見直しの対象です。見直すかどうかは持ち主の判断で、この資料では仕様を変えていません。

## 5. インベントリを開いた画面 (ページ群)

### 5.1 ページ群の考え方

インベントリを開くと、アイコンのタブがまとまった**ページ群**が出ます 【Wiki】【公式】。

- 既定では**左にインベントリとハウジング**、**右にチャット・装備・クラフト**。
- タブをタップすると、そのページが開く。**同じタブをもう一度タップすると、その側が閉じる**。両側を閉じると、インベントリ全体が閉じる 【公式】。
- 片側だけ開けておける (例: 右を閉じてハウジングだけ開き、家の中を広く見る) 【公式】。
- ページ群は**動かせる**。インベントリのページ群は上下に動かせ (ミニマップも同じ高さに動く)、右へも、右側のページ群とぶつからない範囲で動かせる 【Wiki】。
- タブの並びは、縦にも横にもできる 【Wiki】。
- 日本語 Wiki によると、ページ群は左上 (インベントリ。消せない) のほか、左下・右上・右下に置ける。1 つのページ群にはアイコンを 5 個ほどまで。同じアイコンを 2 つのページ群に入れることはできない 【Wiki】(日本語 Wiki。コンソール版も含む記述)。
- 設定「Page Mode」で、ページの開き方の段階を選ぶ。**折りたたみ (Collapsed)**: 主な枠だけ / **拡張 (Expanded)**: 全部の枠 / **クローズ (Closed)**: タブだけ。既定は 3 段階を順に切り替える 【Wiki】。
- 設定「Inventory Camera Movement」(Auto / Always / Never): インベントリを開いたとき、視点を上へずらす 【Wiki】。
- ゲームは止まらない (設定で「Inventory & Menus」にした 1 人プレイでは止まる) 【Wiki】。

2022 年の画像 (16:9) で読み取れる配置 【画像】:

- 左のページ群のタブ: 画面の左、高さの中ほど (x ≈ 5%、y ≈ 67%) に「インベントリ」「ハウジング」の 2 つ。その右 (x ≈ 18%) に、点の格子の「インベントリを開閉する」ボタン。
- 右のページ群のタブ: 右の同じ高さ (x ≈ 80〜97%) に「設定 (歯車)」「チャット」「装備」「クラフト」。

### 5.2 インベントリのページ

| 項目 | 内容 | 根拠 |
|---|---|---|
| 枠の数 | **50 枠** (ホットバー 10 + 本体 40) | 【Wiki】 |
| 並び (縦型ホットバーのとき) | 左に**ホットバーの 2 列 × 5 行**、その右に**本体の 8 列 × 5 行** | 【画像】 |
| ホットバーの扱い | 「左の 10 枠」と「上の 1 行」のどちらをホットバーにするかを選べる | 【Wiki】 |
| コインと弾 | 本体の右に、**小さな枠が縦 1 列** (コイン 4 + 弾 4) | 【画像】【Wiki】 |
| ゴミ箱 | 1 枠。別のものを入れると、前のものは**永久に消える**。死ぬ・世界を出ると空になる | 【Wiki】 |
| 枠の見た目 | 半透明の濃い青の角丸の四角。選んだ枠は黄色 | 【画像】 |

格子の下に、ボタンが 2 つの組で並びます 【画像】【Wiki】。

| 組 | ボタン | 動き |
|---|---|---|
| 左 (選んだアイテムに対する操作) | **Use** (使う) | 選んだアイテムを使う |
| | **Favorite / Unfavorite** (お気に入り) | お気に入りにする・外す。お気に入りは、クイックスタック・並べ替え・ゴミ箱送り・投げる・預けるの対象外になる。枠に縁が付く |

**指の操作** 【Wiki】:

- 枠をタップで選ぶ。ドラッグで動かす・入れ替える。
- インベントリの外へドラッグすると、その方向へスタックごと投げる。
- 設定「Double Tap Gestures」(モバイルの既定 On): アイテムを**ダブルタップ**すると、スタックを分ける・装備するなどの操作になる。

**クイックスタックの 2 つの働き** 【公式】:

- 宝箱を開いていないとき: 近くの**全部の宝箱**へ。同じアイテムがすでに入っている宝箱だけが対象 (空の枠には入れない)。届く範囲は半径 37.5 タイル。
- 宝箱を開いているとき: **その宝箱だけ**へ。
- 1.4.4 から、アイテムが宝箱へ飛んでいく演出がある 【Wiki】。
- 1.4.5 から、似た種類もまとめる方式 (Smart Stack) をツールで選べる 【Wiki】。

### 5.4 クラフトのページ

## 8. 編集の画面

### 8.1 Interface Layout (配置と安全な範囲)

2019 年の公式画像 (横長のスマホ) から読み取れる内容です 【画像】【公式】。

- 画面の中央に小さな窓。上の段に **Safe Region** と **Interface** の切り替え。
- 中の段に **Discard** (赤い ×)、**Default** (黄色い矢印)、**Apply** (緑のチェック)。
- 下の段に **Side / Bottom / Top** (ページ群やタブを置く側)。
- いちばん下に **UI Scale** のスライダー。
- 窓の下に「端末の大きさによって、使えない設定がある」という注意の文。
- **Safe Region** の画面: 上下左右に矢印のつまみがあり、白い枠を動かして、使う範囲を決める。枠の外は赤く塗られる。
- **Interface** の画面: 左上 (インベントリ) と右上 (装備など) の格子、下の左右の仮想コントロールの範囲が色分けで示され、置ける範囲が分かる。

### 8.2 Touch Controls (仮想コントロールの編集)

**1.3.0.7.8 (2020-04) の決まり** 【公式】【Wiki】:

- 今ある部品の動作を**差し替えられる**。「Bindings」のタブから動作を選び、差し替えたいボタンをタップする。
- ボタン専用の動作をスティックに入れると、動作が外れて空のスティックになる。逆も同じ。
- 四角いボタンにできるのはズームだけ。
- 部品は「Controls」の範囲の中で動かせる。**範囲の外へ引きずると赤くなり、そのまま離すと消える**。
- 上のパレットから引きずり下ろして、部品を足せる。動作を選んで、空いた場所をタップしても置ける。
- **部品を重ねられる**。あとから置いたものが上になる。
- 「インベントリ」と「設定」のボタンも動かせるが、もとの側 (左・右) からは出せない。
- **元に戻す・やり直す**ができる。設定やメニューを変えると、履歴は消える。
- **プロファイルは 4 つ**。名前を変えられ、切り替えたときにその名前が画面に出る。
- 「Cycle Profile」ボタンを置くと、プレイ中に切り替えられる。このボタンを置いたプロファイルだけを順に回る。

**1.4.5 (2026-01) の作り直し** 【公式】【Wiki】【画像】:

- 先に部品の**種類** (スティック / ボタン / ラジアル) を選んで置く。あとから動作と**大きさ**を決める。
- 画面の上に窓があり、プリセットの選択 (「New Default」など) と配置の名前 (「Custom Layout」など)、コピーと貼り付け、置く部品の見本 (ボタン・ラジアル・スティック)、Discard、元に戻す・やり直す、Apply が並ぶ。
- 部品を選ぶと、下に窓が出る: **Size** のスライダー、動作の一覧 (ラジアルなら 1〜4 の枠。空きは「Unbound」)、**Delete Control**。
- ボタンごとに**マルチタッチ**を On / Off できる。
- エディタの中で、実際に試せる。

## 9. 持ち主の確認と、既定の動きとの違い

[仕様 18](spec/18-terraria-touch.md) §5 の持ち主の確認 (2026-11-13) を、今回の資料と比べました。**持ち主の実機は、設定や配置を変えた状態の可能性があります。**

| 項目 | 持ち主の確認 | 公開資料の既定 | 考えられる理由 |
|---|---|---|---|
| 左スティックの上 | ジャンプしない | **ダブルタップでジャンプ** | 設定「Up To Jump」が Disabled。または 1 回倒しただけ |
| ホットバー | 横一列 | **縦型 (2 × 5)** | 設定「Hotbar Orientation」が Horizontal |
| 直接タップ | 2026-11-13: カーソルはスティックで動かす (Charon では直接タップを作らないと決定)。2026-11-15: 世界をタッチしてブロックを置けた | **できる** (ブロックの配置も) | 本体には両方の手段がある。仕様 18 の決定は見直しの対象 (§4.12.5) |
| スマートカーソルの切り替え | 左下の `+` | 1.3〜1.4 の既定は**右下** | 1.4.5 の新しい既定、または自分で動かした |
| 使うボタン | 右下の大きな `+` の円 | エイムスティック (1.4 以降のアイコンが `+`) | 同じもの |
| フック | 使うボタンの左隣の小さなスティック。離した向きへ飛ぶ | エイムスティックの左上。スワイプした向きへ飛ぶ | 配置の違い。飛ぶ瞬間は未確認 |
| ズーム | 下の中央に虫めがね 2 つ | 下の左右寄りに 1 つずつ (1.3〜1.4) | 1.4.5 の配置、または自分で動かした |

**Charon への意味**: 「Android 版 Terraria と同じ」を目標にするなら、**どの設定・どの配置を基準にするか**を先に決める必要があります。候補は、(a) 1.4.5 の出荷時の既定、(b) 持ち主の実機の設定、の 2 つです。今の仕様 18 は (b) です。
